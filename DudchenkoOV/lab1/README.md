# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

## Цель
Реализовать библиотеку фильтров, используя только базовые операции над изображением (матрицами) в OpenCV/NumPy, без применения высокоуровневых функций обработки изображений OpenCV (например: `cv2.resize`, `cv2.filter2D`, готовых фильтров и встроенных эффектов).

## Состав проекта
- `image_processing.py` — скрипт с реализацией всех требуемых фильтров и демонстрацией их работы через параметры командной строки.
- `README.md` — описание алгоритмов реализации (мини-отчет).

## Требования к реализации
- Язык программирования: Python.
- Используются только базовые операции над массивами NumPy (индексация, арифметические операции, циклы).
- Высокоуровневые функции обработки изображений OpenCV (например `cv2.resize`, `cv2.GaussianBlur`, `cv2.filter2D` и др.) не используются.
- Допускается использование `cv2.imread` и `cv2.imshow` только для загрузки и отображения изображений.

## Запуск программы

Пример запуска:

```
python image_processing.py -i test_image.jpg -f all
```
Доступные фильтры

resize — изменение разрешения (метод ближайшего соседа)

sepia — фотоэффект сепии

vignette — фотоэффект виньетки

pixelate — пикселизация прямоугольной области

rect_border — прямоугольная одноцветная рамка

decor_border — фигурная одноцветная рамка (wave, zigzag, dots, triangles)

lens_flare — эффект блика объектива

watercolor — текстура акварельной бумаги

all — демонстрация всех эффектов (коллаж)

Примеры использования
Изменение разрешения
python image_processing.py -i test_image.jpg -f resize --new_w 400 --new_h 300
Сепия
python image_processing.py -i test_image.jpg -f sepia
Виньетка
python image_processing.py -i test_image.jpg -f vignette --strength 0.85
Пикселизация области
python image_processing.py -i test_image.jpg -f pixelate --x 50 --y 50 --w 200 --h 200 --pixel_size 12
Прямоугольная рамка (цвет в формате BGR)
python image_processing.py -i test_image.jpg -f rect_border --border_width 15 --border_b 0 --border_g 0 --border_r 255
Фигурная рамка
python image_processing.py -i test_image.jpg -f decor_border --border_width 20 --border_type wave --border_b 0 --border_g 255 --border_r 255
Блик объектива
python image_processing.py -i test_image.jpg -f lens_flare --flare_radius 45 --intensity 0.8
Текстура акварельной бумаги
python image_processing.py -i test_image.jpg -f watercolor --texture_strength 0.5 --seed 1
Алгоритмы реализации (мини-отчет)
1. Изменение разрешения (Nearest Neighbor)

Алгоритм:

Для каждого пикселя нового изображения (x, y) вычисляется соответствующий пиксель исходного изображения:

src_x = int(x * old_w / new_w)
src_y = int(y * old_h / new_h)

Значение пикселя (src_x, src_y) копируется в новое изображение.

Таким образом реализуется масштабирование методом ближайшего соседа без использования cv2.resize.

2. Эффект сепии

Алгоритм:

Работа ведется в формате BGR.

Для каждого пикселя вычисляются новые значения каналов по формулам:

newR = 0.393R + 0.769G + 0.189B
newG = 0.349R + 0.686G + 0.168B
newB = 0.272R + 0.534G + 0.131B

Результат ограничивается диапазоном [0..255].

3. Эффект виньетки

Алгоритм:

Строится маска затемнения по расстоянию до центра изображения.

Расстояние нормируется к диапазону [0..1].

Маска вычисляется как:

mask = 1 - distance * strength

Каждый канал изображения умножается на маску.

Значения ограничиваются диапазоном [0..255].

4. Пикселизация области

Алгоритм:

Выделяется прямоугольная область (x, y, width, height).

Область разбивается на блоки размером pixel_size x pixel_size.

Для каждого блока вычисляется среднее значение цвета.

Весь блок заполняется этим средним значением.

Получается эффект “крупных пикселей”.

5. Прямоугольная рамка

Алгоритм:

Определяются полосы толщиной border_width по краям изображения.

Все пиксели в этих полосах перезаписываются заданным цветом в формате BGR.

Формируется одноцветная рамка.

6. Фигурная рамка

Алгоритм основан на построении булевой маски mask.

В зависимости от параметра border_type:

wave — волнистая граница, высота рамки изменяется по синусоидальному закону.

zigzag — пилообразная форма.

dots — точечная рамка с заданным шагом.

triangles — треугольные зубцы, высота изменяется по линейному закону.

После построения маски все пиксели, попадающие под нее, окрашиваются в заданный цвет.

7. Эффект блика объектива

Алгоритм:

Определяется центр блика (по умолчанию центр изображения).

Для пикселей внутри круга радиуса flare_radius вычисляется добавка яркости:

add = 255 * intensity * exp(-3 * (d / r)^2)

Добавка применяется ко всем каналам.

Результат ограничивается диапазоном [0..255].

8. Текстура акварельной бумаги

Алгоритм:

Генерируется случайная шумовая матрица paper.

Добавляются шумы разных масштабов (многоуровневая текстура).

Шум нормируется к диапазону [0..255].

Изображение умножается на (paper / 255).

Выполняется смешивание:

result = original * (1 - texture_strength) + textured * texture_strength

Получается эффект бумажной акварельной текстуры.
