Практическая работа №3. Классификация изображений с использованием библиотеки OpenCV
Постановка задачи

Цель работы — разработать приложение для классификации изображений трёх достопримечательностей Нижнего Новгорода:

01 — Нижегородский Кремль

04 — Архангельский собор

08 — Дворец труда

Используемый набор данных включает:

фотографии студентов (директория NNSUDataset);

фотографии из открытых источников (директория ExtDataset);

текстовый файл с источниками изображений.

Разбиение на обучающую и тестовую выборки задаётся файлами:

train.txt

test.txt

Разработанное приложение реализует два алгоритма классификации:

Мешок визуальных слов (Bag of Visual Words, BoW)

Нейросетевая модель (ResNet18) с переносом обучения (transfer learning)

При тестировании выводятся:

Accuracy

Precision

Recall

F1-score

Confusion Matrix

Запуск программы

Пример запуска:

python main.py `
   --data_dir ./data `
   --train_split train.txt `
   --test_split test.txt `
   --mode train_test `
   --algo bow

или

python main.py `
   --data_dir ./data `
   --train_split train.txt `
   --test_split test.txt `
   --mode train_test `
   --algo cnn
Алгоритм 1. Мешок визуальных слов (BoW)
Реализация

В реализации используются:

Детектор и дескриптор SIFT или ORB

Кластеризация дескрипторов методом MiniBatchKMeans

Построение BoW-гистограмм

TF-IDF преобразование

Классификатор SVM (RBF kernel)

Этапы работы

Извлечение локальных признаков (SIFT/ORB)

Ограничение количества дескрипторов

RootSIFT-нормализация

Обучение словаря визуальных слов (dict_size = 1000)

Построение нормализованных гистограмм

Обучение SVM-классификатора

Визуализация

Автоматически сохраняются:

ключевые точки (visualizations/keypoints_<class>.jpg)

гистограмма мешка слов (visualizations/bow_hist_<class>.png)

Вывод по BoW

Метод «мешка слов» демонстрирует ограниченную точность (~0.59).
Основная проблема — высокая визуальная схожесть архитектурных объектов и небольшое количество обучающих изображений.

BoW корректно классифицирует Кремль, но значительно хуже различает Собор и Дворец труда.

Алгоритм 2. Нейросетевая модель (CNN, ResNet18)
Реализация

Используется предобученная модель ResNet18.

Особенности реализации:

Загружаются веса ImageNet

Заморожены ранние слои

Разморожены layer3 и layer4

Заменён последний полносвязный слой (fc)

Используется transfer learning

Аугментации

Для обучения применяются:

Resize

RandomResizedCrop

RandomHorizontalFlip

Normalize

Параметры обучения

Epochs: 12

Batch size: 8

Learning rate: 0.0001

Вывод по CNN

Нейросетевая модель показала идеальный результат (Accuracy = 1.0000) на тестовой выборке.

Transfer learning позволил эффективно использовать предварительно обученные признаки ImageNet и успешно адаптировать модель к задаче классификации архитектурных объектов при небольшом размере датасета.

Сравнение методов
Метод	Accuracy
BoW	0.5870
CNN	1.0000

Нейросетевая модель существенно превосходит метод «мешка слов» по всем метрикам качества.

Выводы

Реализованы два алгоритма классификации: BoW и CNN.

Метод BoW показал среднюю точность (~0.59).

CNN с переносом обучения достигла точности 1.0000.

Transfer learning значительно повышает качество классификации на малых выборках.

Архитектурные объекты с похожими текстурными признаками сложно различаются классическими методами.
