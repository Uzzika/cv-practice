# Практическая работа №3. Классификация изображений с использованием библиотеки OpenCV

## Постановка задачи

Цель работы — разработать приложение для классификации изображений трёх достопримечательностей Нижнего Новгорода:

* **01 — Нижегородский Кремль**
* **04 — Архангельский собор**
* **08 — Дворец труда**

Исходный набор данных включает:

* фотографии студентов (директория **NNSUDataset**);
* фотографии из открытых источников (директория **ExtDataset**) и текстовый файл со ссылками.

Тренировочная выборка задаётся файлом `train.txt`, а остальные изображения образуют тестовую выборку. Также поддерживается явный файл `test.txt`.

Разработанное приложение реализует два алгоритма классификации:

* **алгоритм «мешок визуальных слов» (BoW)**,
* **нейросетевой классификатор (ResNet18) с применением переноса обучения (transfer learning)**.

При тестировании программа выводит численные метрики качества классификации: Accuracy, Precision, Recall, F1-score и матрицу ошибок.

## Входные параметры приложения

Программа запускается из командной строки:

```
python main.py \
  --data_dir ./data \
  --train_split train.txt \
  --test_split test.txt \
  --mode train_test \
  --algo bow/cnn
```

### Параметры для BoW

| Параметр       | Назначение                                 |
| -------------- | ------------------------------------------ |
| `--detector`   | ORB или SIFT – выбор детектора/дескриптора |
| `--dict_size`  | размер словаря визуальных слов             |
| `--model_path` | путь сохранения модели                     |

### Параметры для CNN

| Параметр           | Назначение                    |
| ------------------ | ----------------------------- |
| `--cnn_epochs`     | число эпох обучения           |
| `--cnn_batch_size` | размер batch                  |
| `--cnn_lr`         | скорость обучения             |
| `--model_path`     | путь сохранения модели `.pth` |

# Алгоритм «Мешок слов» (Bag of Visual Words)

### Этапы работы:

1. **Извлечение локальных признаков** (ORB/SIFT).
2. **Кластеризация дескрипторов** методом MiniBatchKMeans.
3. **Формирование BoW-гистограмм** — векторов длины `dict_size`.
4. **Обучение классификатора** — LinearSVC.

### ✔ Визуализация BoW

В процессе обучения автоматически сохраняются:

* изображение с найденными ключевыми точками:
  `visualizations/keypoints_<class>.jpg`
* гистограмма мешка слов:
  `visualizations/bow_hist_<class>.png`

### Результаты BoW

```
Accuracy: ~0.60
```

BoW хорошо классифицирует изображения Кремля, однако хуже справляется с Собором и Дворцом труда из‑за разнообразия ракурсов и небольшого количества изображений.

---

# Нейросетевой классификатор (CNN, transfer learning)

Используется предобученная модель **ResNet18**, где:

* все свёрточные слои заморожены,
* дообучается только последний полносвязный слой (`fc`).

### Трансформации

* RandomResizedCrop / CenterCrop
* HorizontalFlip
* Normalize(mean, std)

### Параметры обучения

```
--cnn_epochs 12
--cnn_batch_size 8
--cnn_lr 0.0001
```

# Выводы

1. Модель BoW показала точность около **0.60** — хороший результат, но ограниченный из‑за малочисленного датасета.

3. Нейросеть устойчиво справляется с разнообразием ракурсов и условий съёмки.
4. Добавление дополнительного набора изображений (ExtraDataset) может ещё улучшить качество.
